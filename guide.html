커미션 작업실앱으로 돌아가기

내 서버 만들기 (무료, 약 10분)

커미션 작업실은 자료를 각자의 Supabase 서버에 저장해요. 아래 순서대로 한 번만 만들면, 폰과 컴퓨터에서 같은 자료를 볼 수 있어요. 컴퓨터에서 하는 게 편해요.

1

Supabase 가입하기

  1. supabase.com에 들어가서 가입해요. GitHub 계정이나 이메일로 가입할 수 있어요.
  2. 결제 정보는 필요 없어요. 무료 플랜 그대로 쓰면 돼요.
2

새 프로젝트 만들기

  1. New project를 눌러요.
  2. Name: commission (아무 이름이나 괜찮아요)
  3. Database Password: Generate a password를 눌러 자동으로 만들어요. 앱에서는 안 쓰지만 메모해 두면 좋아요.
  4. Region: Northeast Asia (Seoul)을 골라요.
  5. Create new project를 누르고 1~2분 기다려요.
3

설정 스크립트 붙여 넣기

  1. 왼쪽 메뉴에서 SQL Editor를 눌러요.
  2. 아래 스크립트 복사를 누르고, 빈 편집 칸에 붙여 넣어요.
  3. 오른쪽 아래 Run을 눌러요. Success. No rows returned가 나오면 성공이에요.

"destructive operation" 같은 확인 창이 뜨면 Run this query를 눌러도 괜찮아요. 이 스크립트는 여러 번 실행해도 문제없어요.

4

이메일 인증 끄기 (추천)

  1. 왼쪽 메뉴 Authentication → Sign In / Providers → Email로 가요.
  2. Confirm email을 끄고 Save를 눌러요.

끄지 않으면 앱에서 가입한 뒤 메일함의 인증 링크를 한 번 눌러야 해요. 내 서버엔 나만 가입하니까 꺼도 괜찮아요. 메뉴 이름은 조금 다를 수 있어요.

5

주소와 키 복사하기

  1. 프로젝트 화면 위쪽의 Connect 버튼을 누르거나, Project Settings → API Keys로 가요.
  2. Project URL: https://○○○.supabase.co 모양의 주소
  3. Publishable key: sb_publishable_…로 시작하는 키 (예전 프로젝트라면 anon public 키, eyJ…로 시작)
⚠️ secret 키나 service_role 키는 절대 넣지 마세요. 앱도 막아 두었어요.
6

앱에 연결하고 가입하기

  1. 앱을 열고 내 서버 연결하기를 눌러요. (이미 지나갔다면 오른쪽 위 구름 버튼 → 서버 연결하기)
  2. Project URL과 Publishable key를 붙여 넣고 연결하기를 눌러요.
  3. 처음에는 쓸 이메일과 비밀번호(6자 이상)를 정해서 처음이면 가입하기를 눌러요.
7

폰에서도 쓰기

  1. 폰에서 같은 앱 주소를 열고, 같은 URL·키를 넣은 뒤 이번엔 로그인을 눌러요.
  2. 아이폰: Safari 공유 → 홈 화면에 추가
  3. 안드로이드: Chrome ⋮ → 홈 화면에 추가

폰과 컴퓨터는 거의 바로 맞춰져요. 인터넷이 끊겨도 기기에 먼저 저장되고, 다시 연결되면 올라가요.

알아 두면 좋은 점

  • 무료 용량: 이미지 1GB, 자료 500MB. 이미지는 올릴 때 자동으로 줄어들어서(보기용 1600px + 썸네일 600px) 수천 장을 올릴 수 있어요. 사용량은 앱의 구름 버튼에서 볼 수 있어요.
  • 일주일 동안 안 쓰면 무료 프로젝트가 일시 정지될 수 있어요. 자료는 그대로 있어요. 앱에 "서버에 연결할 수 없어요"가 뜨면 Supabase에 들어가서 프로젝트의 Resume/Restore를 눌러 주세요.
  • 무료 플랜은 계정당 프로젝트 2개까지 켜 둘 수 있어요.
  • 원본 이미지는 서버에 올라가지 않아요. 원본은 내 컴퓨터에 따로 보관해 주세요. 설정 → 백업에서 전체 자료를 ZIP으로 받아 둘 수도 있어요.
